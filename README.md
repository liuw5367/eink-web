# EInk Panel

E-Ink 显示面板 Web 应用，适配掌阅 Neo3 等电子墨水屏设备。

## 技术栈

- React 19
- Rsbuild 2
- Tailwind CSS 3
- Zustand (状态管理)
- TypeScript

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 模式

- **版刻** — 日历风格日期展示
- **晨报** — 日历 + 天气
