# EInk Panel

E-Ink 显示面板 Web 应用，适配掌阅 Neo3 等电子墨水屏设备。

## 技术栈

- React 19
- Rsbuild 2
- Tailwind CSS 3
- Zustand (状态管理)
- TypeScript

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 模式

- **时钟** — 大字时钟 + 天气 + 今日安排 + 每日一句
- **版刻** — 日历风格日期展示
- **资讯** — 天气 + 未来预报 + 新闻
- **晨报** — 日历 + 天气 + 日程
- **壁纸** — 壁纸叠加时钟
